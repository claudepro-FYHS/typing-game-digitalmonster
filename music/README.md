# Background music preview

`theme-preview.mp3` is a recording of the game's background music (one full loop, about 40 seconds),
so you can listen to it without playing the game.

The game itself does not use this file: the music is played live by the code in `js/scene.js`
(`SONG` and `Music`). If the song in `js/scene.js` changes, record a new preview.

Listen online (after the change is merged into `main`):
https://claudepro-fyhs.github.io/typing-game-digitalmonster/music/theme-preview.mp3
